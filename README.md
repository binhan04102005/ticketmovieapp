# 🎬 Movie Ticket Booking App (React Native)

Ứng dụng đặt vé xem phim trực tuyến được xây dựng bằng React Native và Firebase.

## ✨ Chức năng chính
- 🔐 **Xác thực:** Đăng ký, Đăng nhập với Firebase Auth.
- 🎞️ **Phim:** Lấy dữ liệu phim thời gian thực từ TMDB API.
- 🛋️ **Đặt vé:** Sơ đồ chọn ghế Real-time với Firestore.
- 📜 **Lịch sử:** Quản lý danh sách vé đã đặt của từng User.
- 👤 **Cá nhân:** Trang Profile quản lý thông tin và đăng xuất.

## 🛠 Công nghệ sử dụng
- **Frontend:** React Native (Expo), React Navigation.
- **Backend:** Firebase Firestore (Database), Firebase Auth.
- **Icon:** Expo Vector Icons (Ionicons).
- **Thư viện:** Axios (API), Firebase SDK.

## 🚀 Cài đặt
1. Cài thư viện: `npm install`
2. Chạy App: `npx expo start`
